# Power BI Dashboard Deliverables

This directory contains the core Power BI report files and presentation exports for the **Sephora Skincare Commercial & Customer Analytics** project.

---

## 1. File Inventory

| File | Format | Description |
| :--- | :--- | :--- |
| **`Sephora.pbix`** | Report File | Full interactive report with data models, DAX measures, and 3 report pages. |
| **`Sephora.pbit`** | Template File | Lightweight template preserving model schema and visuals without cached data. |
| **`Sephora.pdf`** | Document | Exported high-resolution PDF of all 3 dashboard pages for offline review. |

---

## 2. Report Structure

* **Page 1: Executive Overview:** High-level platform KPIs ($192.54M revenue proxy, 1.09M reviews, 2,351 SKUs), sub-category performance, and quarterly demand trends.
* **Page 2: Brand Dynamics & Assortment:** Brand Pareto curve (Top 10 brands driving 40.89%), price tier distribution ($50–$100 dominance), and assortment pricing power.
* **Page 3: Product Attention & Quality:** Quality risk grid tracking 44 Attention SKUs ($6.27M revenue at risk) and out-of-stock monitoring.

---

## 3. How to Open

* **Power BI Desktop:** Open `Sephora.pbix` to interact with slicers, drill-throughs, and dynamic tooltips.
* **Template Setup:** Open `Sephora.pbit` to connect your local SQL backend or custom data source.
* **Direct Review:** Open `Sephora.pdf` for a quick visual presentation.
